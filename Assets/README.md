# Brand assets

- `driftr.ico` is the official Windows application and installer icon used by DRIFTR.
- `DRIFTR ICON.png` and `ICON.png` retain the supplied source artwork.
- `RyVex.ico` is a retained legacy asset and is not used by DRIFTR.

The ICO uses an emblem-focused crop so the brand remains recognizable at Windows taskbar and title-bar sizes.
